Image Liquify Tool Parameter Reference

This tool distorts image pixels with liquify brush strokes.

Common Parameters (All Tools)

Parameter Description
Brush Radius Brush working range in pixels. Value >0, recommended 20‑200. Larger radius affects wider area, small radius for fine retouching.
Stroke Step Sample interval for dragging strokes. Value ≥1, recommended 5‑40. Smaller value produces smoother dragging but slower computation. Larger value runs faster but may create segmented traces.
Max Distortion Strength Global upper strength limit shared by all liquify operations. 0＜value≤1, recommended 0.3‑0.8. Larger value creates stronger pixel displacement.
Strength Threshold Skip pixels with weight below threshold to improve performance. Range 0‑1, recommended 0.02‑0.08. Setting to 0 keeps all faint deformations. Avoid high values which cause harsh cutoff at brush edge.

Falloff Algorithm (intensity decay from center outward)

Algorithm Description
SMOOTH_QUADRATIC Quadratic decay, strongest at brush center, fades smoothly outward
GAUSSIAN Gaussian decay with soft natural transition
SMOOTH_STEP Smooth step decay
SMOOTH_QUARTIC Quartic decay, intensity drops faster near edge
HARD_CIRCLE Solid hard‑edged brush, constant strength across whole brush area
PS_LIKE Photoshop‑style brush, enables Brush Hardness setting
Parameter Description
Brush Hardness Only effective for PS_LIKE falloff. Controls solid‑core size of brush. Range 0‑1, recommended 0.2‑0.7. 0 = fully feathered soft edge; 1 = solid hard circle with tiny transition rim.

Sampling Algorithm (pixel interpolation after deformation)

Algorithm Description
NearestNeighbor Fastest, noticeable jagged aliasing, no smoothing
BilinearInterpolation Fast computation, suitable for real‑time preview
MITCHELL Balances sharpness and ringing suppression, good for warp and scaling
CATMULL_ROM Produces relatively sharp image output
LANCZOS2 Good image quality with moderate computing cost
LANCZOS3 Best quality, good ringing suppression, higher computational overhead

Edge Mode (handling pixels outside image boundaries)

Mode Description
CLAMP Extend and copy image border pixels
WRAP Repeat image by tiling
MIRROR Mirror‑reflect image content
TRANSPARENT Treat out‑of‑bound area as transparent black
Parameter Description
Start / End Coordinates Start‑end positions of brush stroke. Use identical coordinates for single‑point paint. Coordinates must lie within image bounds.

Tool‑Specific Parameters

Tool Description
Push(PUSH) Shift pixels along drag direction, no extra parameters
Expand / Shrink Expand pushes pixels outward from center; Shrink squeezes pixels toward center.
Displacement Power: Controls push/squeeze intensity, ≥0, recommended 0.2‑0.6. Larger value strengthens effect.
Rotate Clockwise / Counter‑Clockwise Twist pixels within brush region.
Rotate Power: Controls twist magnitude, ≥0, recommended 0.3‑0.7. Larger value intensifies rotation.
Turbulence Add fine random perturbations to image. Useful to reduce artificial smoothness on skin or add fabric texture. Noise pattern differs every run.
  • Turbulence Power: Overall perturbation amplitude, 0‑1, recommended 0.1‑0.35; high values may tear image
  • Noise Frequency: Controls texture density, >0, recommended 0.02‑0.1; higher value yields finer wrinkles
  • Octaves: Controls detail richness, ≥1, recommended 2‑4; minimal improvement beyond 4 layers

Usage Tips

1. Test turbulence with solid‑color or gradient images; use conservative values for portrait editing.
2. Brush Hardness only takes effect under PS_LIKE falloff mode.
3. Smaller Stroke Step yields smoother dragging but reduces performance; increase step for large‑size images.
4. Max Distortion Strength is global master strength. Displacement / Rotate Power are per‑tool sensitivity adjustments.
5. Strength threshold optimizes performance; avoid large threshold values which produce hard circular artifacts around brush perimeter.
